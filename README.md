# Fyntrax Homepage

A modern landing page for Fyntrax, accounting software that actually thinks.

## Features

- Responsive design
- Animated hero background with canvas grid
- AI Agent spotlight section
- Feature showcase
- Testimonials
- Pricing teaser
- Clean, professional styling

## Project Structure

```
fyntrax-site/
├── index.html          # Main HTML file
├── css/
│   └── style.css       # All styles
├── js/
│   └── script.js       # Canvas animation script
├── package.json        # NPM scripts and dependencies
└── README.md           # This file
```

## Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

   Or with auto-open in browser:
   ```bash
   npm run dev
   ```

The site will be available at `http://localhost:3000`

## Technologies Used

- HTML5
- CSS3 (with CSS Variables)
- JavaScript (Canvas API)
- Inter Font from Google Fonts
